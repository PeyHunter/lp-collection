# LP-Collection

A phone app (home-screen web app) for cataloguing vinyl LPs: look up each record on Discogs, store it with its value in PostgreSQL, and sort and search the collection. Read `GLOSSARY.md` for the project's terms and `docs/adr/` for decisions that are hard to reverse.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on PeyHunter/lp-collection (via the `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
